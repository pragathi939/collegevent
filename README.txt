COLLEGE EVENT REGISTRATION SYSTEM - HTML VERSION

Files:
1. index.html      - Home page
2. events.html     - Available events and Register Now
3. register.html   - Student registration form
4. admin.html      - Admin dashboard
5. style.css       - Complete styling

HOW TO RUN:
1. Extract the ZIP file.
2. Open index.html in a browser.
3. Go to Events and click Register Now.
4. Fill in student details and upload an ID card.
5. Open Admin to view registrations.

IMPORTANT:
This is a frontend-only HTML/CSS/JavaScript version.
It uses browser localStorage to demonstrate registration data.

The original case study requires:
HTML + CSS + Node.js + Express.js + MongoDB + Multer.
For the complete backend version, Node.js, Express, MongoDB and Multer
must be added separately.
